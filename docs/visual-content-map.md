# Xpress Your Royalty — Visual Content Map

## Purpose
Define how authentic Xpress Your Royalty imagery should be used across the upgraded public website so photography functions as proof of capability, not decoration.

## Core rule
Prioritize real XYR event work from approved public marketing sources, especially Instagram `@xpressyourroyaltyevents_`, approved Facebook business/personal marketing posts, and existing Wix-hosted originals. Prefer uploading/hosting approved original files in Wix Media rather than hotlinking social-media image URLs.

## Homepage image roles

### Hero image
Select one strongest wide-format event image that immediately communicates elevated event design. Preferred qualities:
- Strong focal point.
- Clean composition with room for overlaid text.
- Clear evidence of décor, draping, backdrop, tablescape, or a polished event transformation.
- No distracting clutter.
- No visible client/private details that should not be promoted.
- Works in desktop and mobile crops.

If no single image satisfies both desktop and mobile, use separate crops from the same approved original.

### Signature service cards
Use four distinct real-work images:
1. Event Design & Décor — styled event setup or tablescape.
2. Draping & Backdrops — strongest draping/backdrop installation.
3. Rentals — visually clear tables/chairs/specialty rental setup.
4. Social & Corporate Celebrations — a professional event scene showing broader event capability.

Avoid using four visually similar backdrop images; the group should demonstrate range.

### Recent Work / Transformations
Use 6–9 curated images, ideally grouped into 2–3 project stories rather than a random gallery. Each project should include a short descriptor such as event type, service provided, and location/region where appropriate.

Possible project-story pattern:
- Hero/full-room image.
- Detail image.
- Before/after or alternate angle when available.

### Why Choose XYR
Use one behind-the-scenes image of setup, preparation, loading, styling, or installation if visually strong. This supports hands-on service and execution credibility.

### Client Journey
No image required for every step. Keep this section visually lighter so the portfolio photography remains dominant.

### Reviews / Social Proof
Use event imagery only when it corresponds to the verified client/project. Do not imply that an unrelated image belongs to a testimonial.

### Social module
Create a curated `Recent From XYR` / `Follow Our Latest Work` section linking to Instagram. Do not make an embedded live social feed the site's only portfolio experience.

## Dedicated page image roles

### Draping & Backdrops
Prioritize:
- Full installation views.
- Close-up fabric/layering details.
- Multiple colors/materials where available.
- Before/after transformation if available.
- Representative finished installs rather than raw fabric-only inventory photos.

### Rentals / Inventory
Prioritize clear representative images by category:
- Tables & Chairs.
- Backdrops & Draping.
- Linens & Table Styling.
- Games & Interactive Rentals.
- AV / Event Equipment.
- Specialty Décor / Add-ons.

Inventory imagery should help a client understand what they are inquiring about. Avoid publishing internal storage or operational photos unless intentionally used as behind-the-scenes content.

### Corporate & Community Events
Use images that show organized, professional setups and community-facing activations. This page should visually distinguish XYR from a wedding-only or party-only brand.

### Micro-Weddings / Selected Wedding Services
Use only actual appropriate wedding or intimate-celebration imagery. Do not use generic stock wedding couples as proof of XYR work.

### Mobile Photo Experience
Use real setup/device/guest-experience photos that accurately represent the current service. Avoid implying equipment or deliverables not actually offered.

## Selection scorecard
Score candidate images 1–5 on:
- Visual impact.
- Demonstrates a priority service.
- Image sharpness/quality.
- Clean composition.
- Brand fit.
- Crop flexibility.
- Permission/public-use confidence.
- Differentiates from other selected images.

Favor candidates scoring 30+ out of 40 for high-visibility homepage use.

## Image processing requirements
For each selected image:
- Preserve the highest-quality original available.
- Create desktop and mobile crops where needed.
- Use responsive Wix image delivery.
- Compress without visibly degrading quality.
- Write descriptive alt text based on what is actually shown.
- Avoid keyword stuffing alt text.
- Use meaningful media/file names when practical.

## Alt text examples
Good: `Burgundy layered event draping with gold accent backdrop by Xpress Your Royalty.`
Good: `White padded event chairs and round tables arranged for a social celebration.`
Bad: `event planner Delaware best luxury event rental wedding décor balloons draping.`

## First image batch target
Collect 12–18 approved candidates, then narrow to:
- 1 hero image.
- 4 service-card images.
- 6–9 recent-work/portfolio images.
- 1 behind-the-scenes image.
- Optional 2–4 page-specific alternates.

## Current-site observation
The live homepage already uses multiple Wix-hosted images, so the upgraded site should continue using the Wix media workflow while replacing or reassigning imagery according to this map.

## Publication gate
Do not publish an image to the upgraded site until:
- Public marketing use is appropriate.
- It accurately represents XYR work/capability.
- Crop quality is acceptable on mobile and desktop.
- Alt text is present where needed.
- It does not expose private client information.
- It is not misleadingly paired with an unrelated testimonial or service claim.
